# 🧁 Bia da Candy's | Landing Page Premium & Arquitetura Front-End

Esta aplicação consiste em uma Landing Page de alto desempenho e totalmente responsiva desenvolvida para a doceria gourmet **Bia da Candy's**. O projeto foi estruturado aplicando conceitos modernos de desenvolvimento Web e padrões de design focados na experiência do usuário (UX) e conversão de clientes.

Desenvolvido como projeto prático para consolidação de competências full-stack e front-end durante o Bootcamp na **Generation Brasil**.

---

## 🎯 Desafios Técnicos & Soluções de Engenharia

Para elevar o nível do projeto além de uma interface estática, foram implementadas boas práticas de desenvolvimento que simulam o ambiente real de produção:

*   **Abordagem Mobile-First:** A folha de estilos (CSS) foi arquitetada de forma incremental, garantindo que a aplicação seja extremamente leve e perfeitamente adaptável desde telas de smartphones compactos até monitores desktop de alta resolução.
*   **Manipulação Dinâmica do DOM:** Utilização de JavaScript vanilla para gerenciar a lógica do catálogo de produtos, permitindo uma seleção fluida e interativa por parte do usuário.
*   **Integração de APIs de Mensageria (WhatsApp):** Tratamento e parsing dos dados capturados no formulário de encomenda para geração de strings de URL válidas, automatizando o envio do pedido estruturado diretamente para o checkout no WhatsApp da empresa.
*   **Clean Code & Semântica HTML5:** Estruturação do código utilizando tags semânticas puras (`<section>`, `<article>`, `<header>`, `<footer>`), o que otimiza drasticamente a acessibilidade e o ranqueamento de SEO nos motores de busca.

---

## 🎨 Design System & Identidade Visual

O layout foi planejado para unir estética e usabilidade, utilizando uma paleta de cores personalizada baseada no branding do cliente:
*   **Cores Predominantes:** Rosa Pastel (suavidade e confeitaria) e Branco (limpeza visual).
*   **Elementos de Destaque:** Detalhes em Girassóis, conferindo personalidade única à marca.
*   **Tipografia & Tipos de Mídia:** Fontes escaláveis e assets de imagem otimizados para carregamento rápido (Lazy Loading implícito).

---

## 🛠️ Stack de Tecnologias

*   **Front-End:** HTML5 Semântico, CSS3 Avançado (Flexbox / Media Queries)
*   **Lógica de Negócio:** JavaScript (ES6+)
*   **DevOps & Deploy:** Git, GitHub e integração contínua (CI/CD) com a plataforma **Vercel**
