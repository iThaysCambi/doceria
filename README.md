# Bia da Candy's - Landing Page

Landing page premium e responsiva para a doceria gourmet **Bia da Candy's**.

## Funcionalidades
- 📱 Mobile-first Design
- 🌻 Tema personalizado (Rosa, Branco e Girassóis)
- 🛒 Catálogo de produtos com seleção rápida
- 📝 Formulário de encomenda integrado com WhatsApp
- 🚀 Pronto para deploy na Vercel

## Como usar
Basta abrir o `index.html` em seu navegador ou fazer o deploy da pasta raiz na Vercel.
